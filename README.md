# pawplanet-site

PawPlanet の公開ページ（招待ページ /get/・プライバシーポリシー・紹介ページ）を独自ドメイン https://pawplanet.01-infinity.com/ で配信するためのリポジトリ。

- 中身は `YoshitetsuSuzuki/pawplanet`（github.io/pawplanet）と同じものを置く。更新するときは両方に同じ変更を入れる。
- アプリの設定ファイル `version.json` はここには置かない（アプリは github.io/pawplanet/version.json を読む。転送経由だと iPhone が読めないため）。
